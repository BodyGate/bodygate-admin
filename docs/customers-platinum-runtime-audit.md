## Confini e rischi verificati

- Nessun import runtime usa `preview-content.ts`, componenti interni di `app/ui-lab`, registry o dati demo.
- `/v2/customers`, `/api/bodygate-v2/customers`, route pubbliche token, Access Control e Pagamenti restano fuori scope.
- Le operazioni distruttive esistenti sono soltanto rettifica/annullamento pagamento e disattivazione blocco; non ne vengono introdotte di nuove.
- Le route dinamiche mantengono `params` asincrono secondo Next.js 16. Le letture server della modifica cliente restano sulla query Supabase preesistente.
